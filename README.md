# ExCaliburr — Windows download

ExCaliburr is a music queue manager for ice skating clubs.
**Website:** https://queue.calibursolutions.com

## Download

Get the current installer from **https://queue.calibursolutions.com/download**.
The file in this repository is named with its version, for example `ExCaliburr-Setup-2.0.11.exe`
(Windows 10 / 11, 64-bit).

No license key is needed to install or try it. Without a key the app runs in free demo mode.
A license key unlocks unlimited skaters and songs.

## Installing

1. Run the installer.
2. Windows may show a blue **"Windows protected your PC"** screen because the installer is not yet
   code-signed. Click **More info**, then **Run anyway**.
3. Open ExCaliburr. Choose **Continue in demo mode**, or paste your license key.

Questions: see https://queue.calibursolutions.com/download
